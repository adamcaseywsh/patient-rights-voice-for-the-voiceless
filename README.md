# Independent Patient Rights Initiative — GitHub Pages

A standalone, static website intended for repository `patient-rights` under GitHub account `adamcaseywsh`.

## Publish for free
1. Sign in to GitHub and create a **public** repository named `patient-rights`.
2. Extract this ZIP locally. Upload the **individual files** (not the ZIP and not the enclosing folder) into the repository root.
3. Commit the files to `main`.
4. Open **Settings → Pages → Build and deployment → Deploy from a branch**. Select `main` and `/ (root)` and save.
5. When deployment finishes, visit https://adamcaseywsh.github.io/patient-rights/ and test the navigation and PDF download.

## Files
- `index.html`: homepage
- `rights.html`: Virginia rights sources
- `reporting.html`: safe reporting guidance
- `support.html`: editable public support declaration and PDF link
- `contacts.html`: government and advocacy contact links
- `style.css`: shared mobile-friendly styling
- `public-petition.pdf`: blank public petition (WSH-focused, reused from existing petition project)

## Important
This is a public static website, not a confidential reporting portal. Never upload completed/signed petitions or private medical records. Government contacts are official websites/contact forms; verify current details before sending. The existing WSH petition site is linked but is not modified by this package.
